METHODS

What is included and what is not

Data origin

The primary data source is the live search service configured by ISPOR's presentations database. The indexed conference count can fluctuate. The separately published August 2026 independent archive is used only for a discrepancy register, not as the dashboard's substitute source.

If the official index snapshot is unavailable, the dashboard displays an explicit source error. It does not silently substitute unverified archive results. Source-index URLs have not all been checked against individual presentation pages.

Import JSON is an optional local exploratory function. A user-imported file is not certified and must not be treated as an official ISPOR census.

Definitions and safeguards

  • A presentation is counted once after deduplication by official URL or stable title.
  • The main dashboard's displayed topic groups come directly from the ISPOR-configured search index. Separate methodological research suggestions are expressly non-evidence.
  • A displayed category edge means the official search index assigned that category to the presentation. It is not a scientific finding.
  • The chart denominator is the number of records in the loaded, filtered corpus.
  • Missing source URLs remain missing; no links are invented.
  • Only one conference year is analysed, so the dashboard does not estimate longitudinal growth. The official index and independent archive have conflicting totals.

Official index vs historical archive: source discrepancy register

The official search-index count fluctuated during collection. These reconciliation categories describe source differences, not fabricated or invalid presentations. The independent archive is used only as a comparator and is not the dashboard's dataset.
