Data origin

The default full-corpus endpoint is the independent ISPOR Europe 2026 Abstract Archive, a 24 August 2026 pre-conference snapshot transcribed from the official ISPOR presentations database. It is not an official verified final-conference census.

If fetching that archive fails, the application displays a smaller set of individually verified official ISPOR pages. The status strip and record count tell you which dataset is active.

Use Import JSON for a more complete or updated export. Imports are processed in your browser.

Definitions and safeguards

  • A presentation is counted once after deduplication by official URL or stable title.
  • Tags are multi-label and are detected with explicit regular expressions.
  • An edge means a keyword theme was detected in a record. It is not a research finding.
  • The chart denominator is the number of records in the loaded, filtered corpus.
  • Missing source URLs remain missing; no links are invented.
  • Only one conference year is available, so there are no claims of longitudinal growth.

Data quality summary

The project includes a reproducible Python extraction script and a generated graph file. Rebuild full data only after checking the archive schema and permissions.
