PSM vs Multi-State Models in Oncology

Learn exactly how a partitioned survival model can represent improved PFS with unchanged OS, then compare that with an explicit progression-to-death structure.

The modelling question

Suppose an oncology treatment delays progression, but has no direct effect on mortality. How should that be represented?

PSM answer: fit or specify PFS and OS separately. If PFS improves while OS is unchanged, patients spend more time progression-free and less time progressed, but total survival is unchanged.
Multi-state answer: reduce the PF to PD transition while leaving death transitions unchanged. If PD carries a higher mortality risk, delaying progression can still create an indirect OS benefit.

This difference is not a mathematical error. It comes from the structural assumptions of the two model classes.

Start with one distinction

Direct mortality effect

Treatment changes a death transition itself, for example PF to death or PD to death.

Indirect mortality effect

Treatment only delays progression, but patients who remain PF avoid some time in a higher-mortality PD state.

No OS effect

Observed or assumed OS is the same in both arms, even though PFS differs.

Key learning target: "no direct effect on OS" and "no OS difference" are not the same statement in an explicit transition model.

How the PSM creates health-state occupancy

In a three-state oncology PSM, progression-free survival (PFS) and overall survival (OS) determine the state proportions directly.

\[PF(t)=PFS(t)\]
\[PD(t)=OS(t)-PFS(t)\]
\[Death(t)=1-OS(t)\]
Therefore: if treatment improves PFS but OS is identical, the PSM shifts living time from PD to PF. It does not need an explicit PF to PD transition probability to do this.

Critical experiment

Move PD → death down until it equals PF → death.

\[P(Death\mid PD)=P(Death\mid PF)\]

If mortality is the same in both living states, delaying progression no longer creates an indirect survival advantage in this simplified model. PFS can still improve, but OS remains essentially unchanged.

Why the two structures can diverge

PSM with fixed OS

Input: OS_Drug(t) = OS_Control(t)
Input: PFS_Drug(t) > PFS_Control(t)
Derived: PD(t) = OS(t) - PFS(t)

The PSM reproduces better PFS with identical survival. The treatment benefit appears as a shift from PD time to PF time.

Explicit transition model

Treatment changes: PF → PD only
Unchanged: PF → death
Unchanged: PD → death

If PD mortality exceeds PF mortality, the model may generate an OS benefit indirectly because treated patients enter PD later.

The important consequence for immature OS

When long-term OS is already observed, a PSM can directly reflect it. The structural issue becomes more important when OS is immature and must be extrapolated.

1
PSM: extrapolate OS and PFS as separate survival functions. Long-term OS is not generated from the progression process.
2
Multi-state model: extrapolate the component transitions. Long-term OS emerges from the transition system.
3
Therefore: the models can make different long-term predictions even if they fit the observed trial period similarly.

A useful stress test

For a treatment whose main evidence is a strong PFS effect with immature OS, ask:

If I believe progression is prognostic for subsequent mortality, should the model allow delayed progression to influence future survival?

If yes, an explicit transition structure can be useful as a structural sensitivity analysis, provided the transition data are strong enough to estimate it reliably.

Decision process: PSM or explicit multi-state structure?

1
What data are actually available?

If you mainly have PFS and OS curves, the PSM maps directly to those endpoints. If you have patient-level event histories, you may be able to estimate PF to PD, PF to death, and PD to death transitions.

2
Is progression expected to affect subsequent mortality?

If the PF and PD states have materially different mortality risks, an explicit transition model can represent that dependence directly.

3
Is OS mature enough to constrain long-term survival?

With mature OS, direct OS modelling may be well anchored. With immature OS, the structural assumptions linking progression and survival matter more.

4
Can the transition models be estimated credibly?

More structure is not automatically more evidence. Sparse post-progression deaths can make the PD to death model unstable.

5
Can structural uncertainty be explored?

When feasible, compare plausible PSM and state-transition specifications rather than treating model structure as fixed.
