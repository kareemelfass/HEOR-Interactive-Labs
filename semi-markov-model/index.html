1. Why does memory matter?

Two patients can occupy the same health state at the same model time but face different future risks if prognosis depends on time already spent in that state.

Markov property: conditional on the current state and explicitly modelled variables, future transitions do not additionally depend on the path used to reach that state.
Markov does not mean constant risk. A time-inhomogeneous Markov model can use \(h(t)\). Semi-Markov dependence arises when the relevant clock is history-dependent, such as time since state entry \(u\).
\[h_{PD,D}(u)=\frac{\gamma}{\lambda}\left(\frac{u}{\lambda}\right)^{\gamma-1},\quad \lambda=10,\ \gamma=1.5\]

2. Which clock is the model using?

Before making a transition time-dependent, identify the clinically relevant time scale.

Clock-forward \(t\)

Time since model or study entry. It never resets.

Clock-reset \(u\)

Time since entering the current state. It resets at state entry.

6. Giving the cohort memory: tunnel states

PF→PD₀→PD₁→PD₂→PD₃→…
\[PD_{u+1,t+1}=PD_{u,t}[1-p_D(u)]\]
Equivalent views: explicit tunnel states \(PD_0,PD_1,\ldots\), or one clinical PD state with a duration dimension \(PD_{t,u}\).
Takeaway: tunnel states do not define semi-Markov behaviour. They encode the duration information the transition process needs.
