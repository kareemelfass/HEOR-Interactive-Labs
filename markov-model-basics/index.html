Markov Model Basics Lab

Build a simple cohort Markov model, change the transition probabilities, and watch the cohort move through health states cycle by cycle.

1. Health states

A cohort Markov model divides the clinical pathway into mutually exclusive health states. At the end of every cycle, each person is in exactly one state.

Example: all 1,000 patients start in Stable disease. Over time, some remain stable, some progress, and some die.

2. Transition probabilities

A transition probability is the probability of moving from one state to another during one cycle. Each row of the transition matrix must sum to 1.

Next cycle state vector = Current cycle state vector × Transition matrix

In this lab, Death is absorbing: once entered, patients remain there.

3. The Markov trace

The Markov trace is the table of state occupancy over time. It shows how many people are expected to occupy each state after every cycle.

What to watch: increase Stable → Progressed and the Stable curve should fall faster. Increase Progressed → Death and the Progressed curve may become lower even though progression itself has not improved.

4. Attach costs and utilities

State rewards attach a value to time spent in each state. Here, each state has a cost and a utility weight. Utility is multiplied by the cycle length to generate QALYs.

Cycle cost = Σ(state occupancy × state cost)
Cycle QALYs = Σ(state occupancy × state utility × cycle length)

This introductory lab intentionally leaves out half-cycle correction and probabilistic sensitivity analysis.

5. Interpretation

The model is not tracking named individuals. It propagates the expected proportion of a cohort through a transition matrix. The key outputs are therefore expected state occupancy, expected costs, and expected QALYs.

Core check: every transition row sums to 1 and the total cohort remains constant across cycles.
