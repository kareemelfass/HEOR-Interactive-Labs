# HEOR Interactive Labs

Interactive, method-focused tutorials for health economics and outcomes research (HEOR), survival extrapolation, cost-effectiveness modelling, and health technology assessment.

## Labs

### 01. Mixture Cure Models

An interactive tutorial covering:

1. What a mixture cure model is
2. When it may be appropriate, with published examples
3. An interactive example showing how the cure fraction and uncured survival combine
4. NICE DSU guidance and ISPOR-published methodological evidence
5. Core references

Open the lab at `labs/mixture-cure-model/`.
